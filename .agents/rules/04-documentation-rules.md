# Documentation Rules

Documentation must distinguish:

1. Planned methodology
2. Actual implementation
3. Actual experimental results
4. Interpretation

Never present planned values as measured values.

Never fabricate:
- dataset statistics
- model metrics
- experiment results
- training times
- parameter counts

Keep README.md concise and useful.

Keep detailed methodology in `docs/`.

Document important design decisions.

Document deviations from the original plan.

Use tables for experiment comparisons.

Use figures for important experimental results.

When a result is pending, explicitly mark it as pending.
