# ML Experiment Skill

Use this skill whenever working on a model experiment.

## Procedure

1. Read `docs/PROJECT_SPEC.md`.
2. Read the relevant project rules.
3. Inspect the current implementation.
4. Read `docs/EXPERIMENTS.md`.
5. Define the experiment question.
6. Define the hypothesis.
7. Identify the independent variable.
8. Identify controlled variables.
9. Define the required metrics.
10. Implement the smallest necessary change.
11. Run the experiment.
12. Verify that execution completed successfully.
13. Save metrics and artifacts.
14. Update `docs/EXPERIMENTS.md`.
15. Summarize the measured result.
16. Provide a cautious interpretation.

## Critical Rules

Never fabricate results.

Never report an experiment as complete if it was not executed.

Never use test performance to select a model or hyperparameters.

Never silently change experimental conditions.

Keep experiments reproducible.
