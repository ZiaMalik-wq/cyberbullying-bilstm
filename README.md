# Fine-Grained Cyberbullying Classification Using Bi-LSTM

University Artificial Neural Networks and Deep Learning project.

## Objective

Classify social-media text into six cyberbullying categories using neural
networks trained from scratch.

## Main Model

Bi-LSTM with a trainable embedding layer.

## Constraint

No pretrained models or pretrained word embeddings are used.

## Technologies

- Python
- TensorFlow / Keras
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Development

The project is developed using Google Colab / Kaggle for GPU training.
